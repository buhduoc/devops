# hyh-6-hyprland
Este es un Proyecto desarrollado en QML/Python enfocado en **Hyprland**.

Enfocado en una Estetica Minimalista para Hyprland.

---

## Ejecucion y Instalacion

1. **clonar el repositorio**
   ```bash
   git clone https://github.com/buhduoc/pre_prueba
   ```
2. **Esperar A que se complete la descarga**
3. **Reiniciar el sistema**
