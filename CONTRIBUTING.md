# Guía para Colaboradores

Muchas gracias por sumarte a este proyecto. El código tiene que estar limpio; para esto, puedes seguir los siguientes pasos:

---

## Git Flow

1. No subir cambios en `main`.
2. Crear una rama de trabajo. Ejemplo:
   - `feature/` funciones nuevas.
   - `fix/` corregir errores.

## Hacer Pruebas

Antes de realizar un pull request, asegúrate de haber hecho pruebas:

1. Verificar `README.md`.
2. Que esté compilado correctamente.
