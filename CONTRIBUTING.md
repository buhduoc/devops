# Guia para Colaboradores
Muchas Gracias por sumarte a este proyecto, el codigo tiene que estar limpio para esto puede seguir los siguientes pasos..
---
## Git Flow
1. No subir cambios en`Main`
2. Crear una rama de trabajo, Ejemplo:
   - `Feature/`funciones nuevas.
   - `fix/`corregir errores.
## Hacer Pruebas
Antes de realizar un pull request asegurate de haber hechos pruebas..
1. Verificar`README.md`.
2. Que este compilado correctamente.
