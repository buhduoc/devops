# Guia de Seguridad
Bienvenido a la guia de seguridad, aqui puedes ver informacion sobre algunos usos de opciones que nos permiten tener mas seguridad en nuestro proyecto
---
1. Code Scaning
   - Actualmente github permite el uso de `CodeQL` el cual va realizar un analisis al codigo y buscara vulnerabilidades de seguridad o errores
2. Dependabot
   - Es una herramienta de github el cual actualiza las dependencias de software, donde este va a analizar el codigo, al encontrar vulnerabilidades esta creara un `pull request` para corregirlas
